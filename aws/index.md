## Minimum requirements and grade 1

Each AWS Academy course is treated as a separate assessment component.

To pass an AWS Academy course with at least grade 1, you must complete both of the following requirements:

1. Submit handwritten notes for at least **70% of the required lecture videos**.
2. Complete at least **70% of all AWS Academy activities** in that course.

Both requirements must reach at least 70%. A result below 70% does not meet the requirement.

AWS Academy activities include labs, tests, knowledge checks, Course Assessments, and other activities included in the course.

No individual activity is mandatory. The requirement is based on completing at least 70% of all activities in the AWS Academy course.

The AWS **Course Assessment** is therefore treated like any other AWS Academy activity. It is included when calculating the 70% activity requirement, but completing the Course Assessment itself is not mandatory if the 70% requirement is reached through other activities.

Meeting both 70% requirements gives you grade 1 for that AWS course and makes you eligible to take its exam.tuni.fi exam.

The teacher verifies that the requirements have been met before you take the exam.

If either requirement is below 70%, the AWS course assessment component is failed (grade 0).

## exam.tuni.fi exams and grades 2–5

There is one exam.tuni.fi exam for each AWS Academy course:

- AWS Cloud Foundations
- AWS Cloud Architecting
- AWS Cloud Developing
- AWS Cloud Operations

If you complete both 5-credit TAMK courses, you therefore take **four separate exams**.

The exams are available from **30.11.2026 to 28.02.2027**.

You must meet the 70% handwritten-notes requirement and the 70% AWS-activities requirement for the corresponding AWS course before taking its exam.

Exam questions are selected randomly, so students may receive different questions.

The exam result determines the grade for that AWS course as follows:

| Exam result | Grade |
| --- | --- |
| Below 60% | 1 |
| At least 60% | 2 |
| At least 70% | 3 |
| At least 80% | 4 |
| At least 90% | 5 |

If you meet both 70% minimum requirements but do not take the exam, your grade for that AWS course is **1**.

If you take the exam but score below 60%, your grade remains **1**.

## Retaking exams

A failed exam may be retaken **twice**.

A passed exam may be retaken **once** to improve the grade.

The best achieved grade remains valid. Your grade will not decrease if a later attempt produces a lower result.

These rules apply to all exam.tuni.fi exams in these courses.

## Final TAMK course grade

Each 5-credit TAMK course contains two AWS Academy course assessment components.

For **4A00HK44-3002**:

- AWS Cloud Foundations
- AWS Cloud Architecting

For **4A00HK45-3002**:

- AWS Cloud Developing
- AWS Cloud Operations

Both components must be passed.

The final TAMK course grade is the arithmetic mean of the two component grades, rounded to the nearest whole number using normal rounding rules. A result ending in 0.5 is rounded up.

Examples:

- grades 2 and 3 → final grade 3
- grades 4 and 5 → final grade 5
- grades 1 and 5 → final grade 3

If either AWS course component is failed (grade 0), the entire corresponding 5-credit TAMK course is failed.

## AWS Course Assessment, TAMK exam, and AWS badge

There are several different assessments in AWS Academy and TAMK. Do not confuse them.

### AWS Course Assessment

The **AWS Course Assessment** is a multiple-choice assessment inside AWS Academy.

It is counted as one of the AWS Academy activities and is therefore included in the 70% activity requirement.

It is not the TAMK grading exam.

### exam.tuni.fi exam

The **exam.tuni.fi exam** is the TAMK grading exam.

There is one separate exam for each AWS Academy course. This exam determines grades 2–5.

### AWS Academy badge

AWS Academy may offer its own final assessment for earning an AWS Academy digital badge.

This assessment is separate from the TAMK exam.tuni.fi exam.

The AWS Academy badge and its associated assessment are **optional** and do not affect your TAMK course grade.

## Practical tips

- When starting a lab, allow **5–10 minutes** for the environment to initialize fully.
- Read the lab instructions carefully before making changes in the AWS Console.
- If you cannot find something in the instructions, use your browser's find function (`Ctrl+F` or `Cmd+F`).
- AWS updates its Console regularly, so screenshots or individual steps in a lab may occasionally differ from the current interface.
- If the AWS Console has changed, identify the equivalent current setting or action. You may use documentation or AI tools to help locate it.
- Some AWS operations, such as provisioning or deployment, take time to complete. If a command fails immediately after creating or changing a resource, wait 10–20 seconds and try again.
- After completing a lab or activity, allow a few minutes for AWS Academy to register the result before submitting it.
- If necessary, submit the activity again after waiting.
- In your notes, focus on understanding what each AWS service does, why it is used, and how it relates to the other services in the architecture.

## Turning handwritten notes into PDFs

### macOS with an iPhone

Use the Notes app and **Continuity Camera → Scan Documents**, then save or export the scanned document as a PDF.

### macOS with a scanner

Scan your handwritten pages, open the images in Preview, and use **File → Print → PDF → Save as PDF**.

### Windows with Microsoft Lens

Scan your notes in **Document** mode and export them as a PDF.

### Windows with a scanner

Scan your handwritten pages and use **Microsoft Print to PDF** to create the PDF file.

### Mobile devices

Adobe Scan and similar document-scanning applications can scan handwritten pages directly into PDF files.
