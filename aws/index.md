# Cloud and AWS Studies Overview

This page is an overview of the two 5 credit TAMK courses built on AWS Academy content.
Each course is self-paced and delivered as a MOOC.
There is no teacher-led instruction.
All lectures, labs, and knowledge checks are completed inside the AWS Academy platform.

## Which AWS Academy courses give which credits

| TAMK course | AWS Academy course(s) | Credits |
| --- | --- | --- |
| 4A00HK44-3002 Johdatus pilvipalveluihin ja arkkitehtuuriin | AWS Cloud Foundations + AWS Cloud Architecting | 5 op |
| 4A00HK45-3002 Pilvipohjainen ohjelmistokehitys ja käyttöönottoprosessit | AWS Cloud Developing + AWS Cloud Operations | 5 op |

Take the courses in this order: Foundations, Architecting, Developing, Operations.

## Handwritten notes

Write handwritten notes for every lecture video required by your module list.
For each video, include the most important topics, what you learned, and what was unclear.
You may write your notes in Finnish or in English.

- [AWS Cloud Foundations](cloud-foundations-notes.txt)

## Practical tips

- When starting a lab, allow 5 to 10 minutes for it to fully initialize.
- If you cannot find something in the AWS Console, double-check the instructions and use your browser's find function (Ctrl+F or Cmd+F).
- AWS updates its console UI over time, so lab steps can be slightly outdated, use your judgment or AI tools to find the equivalent step.
- Some actions need a short delay to finish in the background, such as provisioning or deployment, if a command fails, wait 10 to 20 seconds and try again.
- After finishing a lab or activity, wait a few minutes before clicking submit, and click submit again if needed.
- Take notes on what each AWS service does and why you used it, your future self will thank you.

## Turning handwritten notes into PDFs

- macOS with an iPhone: use the Notes app, Continuity Camera, Scan Documents, then export the scan as a PDF.
- macOS with a scanner: scan to images, open them in Preview, then use File, Print, PDF, Save as PDF.
- Windows with Microsoft Lens: scan in Document mode, then export as PDF to OneDrive, phone storage, or email.
- Windows with a scanner: scan to images, then use Microsoft Print to PDF from the print dialog.
- Adobe Scan on mobile also saves scans directly as PDF, then share the file to your computer.
